# [BUG] BOOK · Android — Save changes thất bại hiện thông báo lỗi rỗng (chỉ biểu tượng `!`), không lưu

## Thông tin chung
- **ID:** BUG_book_1792454703_TC187
- **Severity:** 🟡 Minor
- **Priority:** P2
- **Nền tảng:** `mobile` (Android)
- **Môi trường:** Production `https://book.canhnt14.com` | Emulator `Pixel_10_Pro_XL_API_37` · Android 17 · WebView `153.0.8010.36` | Windows 11 (máy chạy emulator) | `1344×2992`, hướng dọc, locale `en-US`
- **Build / Version:** app `book.canhnt14.com` `1.0 (versionCode 1)` bản debug (Hybrid — Capacitor), cài 22-09-2026
- **Test case liên quan:** `BK_BOOK_TC_187`
- **REQ ID liên quan:** `REQ-BK-BOOK-155` (kỳ vọng — `AMB-BK-BOOK-38` ✅ chốt là lỗi, `DEMO-AMB-2010`). `REQ-BK-BOOK-46` · `47` (lưu thành công trên Android) chưa kiểm được
- **Test data đã dùng:** sách test còn sót từ đợt API `Auto BKAPI NoPrice <timestamp>` — sách **mồ côi** (tác giả đã bị xoá); Book name thêm hậu tố ` Edited`. Sách **đã xoá** sau khảo sát (20-10-2026, `GET /api/book/<id>` → 404). Tài khoản thao tác: tài khoản test do tester đăng nhập sẵn trên app
- **Ngày phát hiện:** 20-10-2026

## Steps to Reproduce
1. Chuẩn bị 1 sách mồ côi (tạo sách qua web/API bằng 1 tài khoản, rồi xoá tài khoản tác giả đó) — pre-condition `SM-C` của `BK_BOOK_TC_187`
2. Đăng nhập app bằng tài khoản test → tab `Book` → `Filter`, tìm sách đó
3. Bấm nút bút trên thẻ — màn `Modify book` mở
4. Thêm ` Edited` vào cuối `Book name`
5. Cuộn xuống, bấm `Save changes`, quan sát đáy màn hình ngay trong 3 giây (thông báo mất sau ~2 giây — nên quay màn hình)
6. Bấm tab `Book`, tìm lại sách

## Expected Result
Theo `REQ-BK-BOOK-155`:
- Server không lưu → thông báo nổi có **chữ** mô tả lỗi, form giữ dữ liệu vừa sửa
- (Nếu lưu được → `Book updated successfully.` và về danh sách)
- Bước 6: tên trên thẻ khớp với thông báo

## Actual Result
- Thông báo nổi chỉ có biểu tượng `!` đỏ và nút ×, **không có chữ**
- Tên sách **không** đổi (đọc lại API công khai `GET /api/book?search=<tên>` → `name` cũ)
- Người dùng không biết vì sao không lưu được
