# [BUG] BOOK · Android — Create book chỉ hiện thông báo đang tải rồi mất, không tạo được sách

## Thông tin chung
- **ID:** BUG_book_1792454702_TC143
- **Severity:** 🔴 Critical
- **Priority:** P1
- **Nền tảng:** `mobile` (Android). Web tạo được sách với cùng dữ liệu (REQ-BK-BOOK-39)
- **Môi trường:** Production `https://book.canhnt14.com` | Emulator `Pixel_10_Pro_XL_API_37` · Android 17 · WebView `153.0.8010.36` | Windows 11 (máy chạy emulator) | `1344×2992`, hướng dọc, locale `en-US`
- **Build / Version:** app `book.canhnt14.com` `1.0 (versionCode 1)` bản debug (Hybrid — Capacitor), cài 22-09-2026 — cùng bản build ở cả 2 lượt khảo sát
- **Test case liên quan:** `BK_BOOK_TC_143`
- **REQ ID liên quan:** `REQ-BK-BOOK-147` (kỳ vọng — `AMB-BK-BOOK-34` ✅ chốt là lỗi app Android, `DEMO-AMB-2609`). Cùng hành vi web `REQ-BK-BOOK-39`. Kéo theo: `REQ-BK-BOOK-46` · `47` (lưu thành công trên Android) chưa kiểm được vì cần sách do phiên tạo
- **Test data đã dùng:** Book name `Auto Mobile Book <timestamp> Tiếng Việt` (26-09-2026) · `Auto Mobile Book <timestamp>` (20-10-2026) · 1 ảnh PNG `auto_mobile_book_<timestamp>.png` đẩy vào `/sdcard/Download/` của emulator · Regular price `50000` · Categories `Technology`. **Không** có bản ghi nào được tạo trên server (API công khai trả 0 bản ghi). Tài khoản thao tác: tài khoản test do tester đăng nhập sẵn trên app
- **Ngày phát hiện:** 26-09-2026 (thử lại 20-10-2026 — vẫn lỗi)

## Steps to Reproduce
1. Đăng nhập app bằng tài khoản test → tab `Book` → bấm `+ New book` — form `Create a new book` mở
2. Nhập `Book name`
3. Chọn 1 ảnh PNG có sẵn trong máy (Photo Picker)
4. Chạm ô `Regular price`, gõ `50000`
5. Bấm ô `Categories`, gõ `Technology`, chọn mục `Technology`
6. Bấm `Create book`, quan sát cuối màn hình trong 10 giây
7. Bấm tab `Book` → `Filter`, gõ tên sách vào ô `Search book...`

## Expected Result
Theo `REQ-BK-BOOK-147` (cùng hành vi web `REQ-BK-BOOK-39`):
- Thông báo nổi `Book created successfully.`
- Tự quay về danh sách `Book Management`, sách mới đứng đầu khi sắp `Newest`
- Bước 7: tìm theo tên ra đúng 1 sách

## Actual Result
- Một thông báo nổi có vòng xoay hiện **< 1 giây** rồi mất — nội dung `Uploading image...` (26-09-2026) / `Uploading book...` (20-10-2026)
- **Không** có thông báo thành công hay lỗi nào
- Vẫn đứng ở form, dữ liệu nhập còn nguyên
- Không có sách nào được tạo: tìm theo tên trên app → không có thẻ; đọc API công khai `GET /api/book?search=<tên>` → 0 bản ghi

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn (4/4 — 26-09-2026 2/2 · 20-10-2026 2/2)
- **Workaround (nếu có):** Tạo sách trên web hoặc qua API. Bộ TC Android đang dựng sách `SM-A` bằng web/API ở bước setup vì lỗi này
- **Nghi ngờ root cause (nếu phân tích được):** Không suy đoán — cần Dev xác minh. Nội dung thông báo đang tải đổi giữa 2 lượt (`Uploading image...` → `Uploading book...`) trên **cùng** bản build `1.0`. Quan sát chung của cụm lỗi: trên Android **mọi thao tác gửi dữ liệu** đã thử đều lỗi — Save Profile ([BUG_auth_1792454704_REQ122](../../auth/mobile/BUG_auth_1792454704_REQ122.md)) · Create book (bug này) · Update user ([BUG_user_1792454701_TC152](../../user/mobile/BUG_user_1792454701_TC152.md)) · Save changes ([BUG_book_1792454703_TC187](BUG_book_1792454703_TC187.md)); còn **Delete** (user, sách) chạy được. Web làm được cùng các thao tác ghi này
