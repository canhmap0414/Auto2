# [BUG] AUTH · Android — Save Profile báo `Error in processing request`, hồ sơ không được cập nhật

## Thông tin chung
- **ID:** BUG_auth_1792454704_REQ122 — hậu tố `REQ122` vì `REQ-BK-AUTH-122` **chưa có TC Android** (bộ TC mobile của AUTH mới có phần Đăng nhập · Đăng ký)
- **Severity:** 🟠 Major
- **Priority:** P2
- **Nền tảng:** `mobile` (Android). Web cập nhật được với cùng thao tác (REQ-BK-AUTH-103 — `BK_AUTH_TC_174`)
- **Môi trường:** Production `https://book.canhnt14.com` | Emulator `Pixel_10_Pro_XL_API_37` · Android 17 · WebView `153.0.8010.36` | Windows 11 (máy chạy emulator) | `1344×2992`, hướng dọc, locale `en-US`
- **Build / Version:** app `book.canhnt14.com` `1.0 (versionCode 1)` bản debug (Hybrid — Capacitor), cài 22-09-2026
- **Test case liên quan:** `BK_AUTH_TC_196` (biến thể `a` sửa Name · `b` sửa Address — [part_03_mobile_ho_so.md](../../../../testcases/_book-api/auth/mobile/parts/part_03_mobile_ho_so.md), thêm 20-10-2026 sau khi mở bug, gắn `@KnownBug`). TC web tương ứng để đối chiếu: `BK_AUTH_TC_174` (`REQ-BK-AUTH-103` — Cập nhật tên hồ sơ thành công)
- **REQ ID liên quan:** `REQ-BK-AUTH-122` (kỳ vọng — `AMB-BK-AUTH-34` ✅ chốt là lỗi app Android, `DEMO-AMB-2609`). Cùng hành vi web `REQ-BK-AUTH-103`. Các REQ My Profile khác trên Android (đổi mật khẩu…) không kiểm được tới khi sửa
- **Test data đã dùng:** tài khoản test `auto_demo_account_<timestamp>@auto.test` do tester tạo trước và đăng nhập sẵn (dùng chung Web · API · Android); sửa Name, có lần điền đủ Division `Thành phố Hà Nội` · Ward `Phường Hoàn Kiếm` · Address `auto_profile_<timestamp> so 1`. Hồ sơ **không** thay đổi sau 3 lần thử, form đã Reset
- **Ngày phát hiện:** 26-09-2026

## Steps to Reproduce
1. Đăng nhập app bằng tài khoản test → đứng ở `Dashboard`
2. Bấm avatar → `Profile` — màn `My Profile` mở, dữ liệu điền sẵn
3. Sửa ô `Name` (để trống `Old Password` · `Password` · `Password Confirmation`)
4. Bấm `Save Profile`, quan sát đáy màn hình

## Expected Result
Theo `REQ-BK-AUTH-122` (cùng hành vi web `REQ-BK-AUTH-103`):
- Thông báo `Updated profile successfully.`
- Thẻ Dashboard hiện `Welcome <Name mới>`

## Actual Result
- Thông báo nổi `Error in processing request` (biểu tượng `!` đỏ)
- Name **không** đổi — Dashboard, menu avatar và mở lại `My Profile` đều vẫn tên cũ

## Evidence
- Screenshot: [android_profile_save_error_toast.png](../../../../requirements/_book-api/auth/mobile/evidence/android_profile_save_error_toast.png) — màn `My Profile` đã điền đủ địa chỉ, thông báo `Error in processing request`
- Error log / Stack trace: không thu được — chưa dựng proxy, WebView không bật gỡ lỗi
- Console / Network log: không quan sát được request từ app

- **Workaround (nếu có):** Sửa hồ sơ trên web
- **Nghi ngờ root cause (nếu phân tích được):** Không suy đoán — cần Dev xác minh. Nên thử cùng tài khoản trên web để loại trừ yếu tố tài khoản (`AMB-BK-AUTH-34`).
