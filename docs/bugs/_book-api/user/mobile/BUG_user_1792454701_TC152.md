# [BUG] USER · Android — Update user báo `Error in processing request`, thay đổi không được lưu

## Thông tin chung
- **ID:** BUG_user_1792454701_TC152
- **Severity:** 🔴 Critical
- **Priority:** P1
- **Nền tảng:** `mobile` (Android). Web lưu được với cùng thao tác (REQ-BK-USER-37 — `BK_USER_TC_013`)
- **Môi trường:** Production `https://book.anhtester.com` | Emulator `Pixel_10_Pro_XL_API_37` · Android 17 · WebView `153.0.8010.36` | Windows 11 (máy chạy emulator) | `1344×2992`, hướng dọc, locale `en-US`
- **Build / Version:** app `book.anhtester.com` `1.0 (versionCode 1)` bản debug (Hybrid — Capacitor), cài 22-09-2026
- **Test case liên quan:** `BK_USER_TC_152` — fail cả 2 biến thể `BK_USER_TC_152-a` (đổi Name) · `BK_USER_TC_152-b` (tắt `Active for login`)
- **REQ ID liên quan:** `REQ-BK-USER-129` (kỳ vọng — `AMB-BK-USER-21` ✅ chốt là lỗi app Android, `DEMO-AMB-2010`). Cùng hành vi web `REQ-BK-USER-37`. `REQ-BK-USER-37` · `38` · `39` · `40` trên Android bị chặn tới khi sửa
- **Test data đã dùng:** user test còn sót từ đợt Web `auto_web_1790272684_b@auto.test` — Name sửa thành `Auto Web B 1790272684 Mobile`; 2 ô mật khẩu để trống. Bản ghi **đã xoá** sau khảo sát (20-10-2026). Tài khoản thao tác: tài khoản test do tester đăng nhập sẵn trên app
- **Ngày phát hiện:** 20-10-2026

## Steps to Reproduce
1. Đăng nhập app bằng tài khoản test, tắt hẳn app rồi mở lại (tránh lỗi validation dính giữa các hộp thoại — `REQ-BK-USER-124`)
2. Bấm tab `User`, chạm ô tìm kiếm, gõ email của user test
3. Bấm ⋮ ở dòng user đó → `Edit` — hộp thoại `Update user` mở
4. Sửa ô `Name` (để **trống** 2 ô `Password` · `Password Confirmation`)
5. Bấm `Update`, quan sát đáy màn hình trong 3 giây
6. Biến thể `b`: lặp lại bước 1–5, lần này chỉ tắt công tắc `Active for login`

## Expected Result
Theo `REQ-BK-USER-129` (cùng hành vi web `REQ-BK-USER-37`):
- Thông báo nổi `Updated successfully.`
- Hộp thoại `Update user` đóng
- Dòng của user hiện Name mới (biến thể `b`: cột `Active` hiện `Inactive`)

## Actual Result
- Thông báo nổi `Error in processing request` (biểu tượng `!` đỏ)
- Hộp thoại `Update user` **vẫn mở**
- Dữ liệu user **không đổi**: đọc lại qua API công khai `GET /api/user?search=<email>` → `name` cũ, `updatedAt` cũ; biến thể `b` → `isActive` vẫn `true`

- Screenshot: [android_user_update_error_processing.png](../../../../requirements/_book-api/user/mobile/evidence/android_user_update_error_processing.png) — hộp thoại `Update user` còn mở, thông báo `Error in processing request`
- Error log / Stack trace: không thu được — chưa dựng proxy, WebView không bật gỡ lỗi
- Console / Network log: không quan sát được request từ app. Kết quả "không lưu" xác nhận bằng cách đọc lại API công khai (mục Actual Result)
